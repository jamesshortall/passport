AppPassport — Logo Pack
=======================
Part of The Travel Technician.

WHAT'S INCLUDED
---------------
Horizontal lockup (mark + "AppPassport" + tagline):
  apppassport-logo.svg              Full-color, scalable  → use on LIGHT backgrounds
  apppassport-logo-1600.png         Full-color, 1600px wide, transparent
  apppassport-logo-800.png          Full-color, 800px wide, transparent
  apppassport-logo-reverse.svg      White wordmark, scalable → use on DARK backgrounds
  apppassport-logo-reverse-1600.png Reverse, 1600px wide, transparent
  apppassport-logo-reverse-800.png  Reverse, 800px wide, transparent

Square mark (the badge only — for app icons, avatars, favicons, social profiles):
  apppassport-mark.svg              Scalable
  apppassport-mark-1024.png         1024x1024, transparent
  apppassport-mark-512.png          512x512, transparent
  apppassport-mark-256.png          256x256, transparent
  apppassport-mark-128.png          128x128, transparent

WHICH FILE DO I USE?
--------------------
- Print, or anywhere you need it razor-sharp at any size  → the .SVG files
- Web / docs / slides on a light background               → apppassport-logo-*.png
- Web / docs / slides on a dark background or photo        → apppassport-logo-reverse-*.png
- App icon, social avatar, favicon, small square space     → apppassport-mark-*.png

BRAND COLORS
------------

Gold    #C8A24A   (stamp accent — shared with Cardmaster)
Paper   #F7F5F0   (background)

USAGE GUIDELINES
----------------
- Keep clear space around the logo equal to the height of the "A" in AppPassport.
- Don't stretch, recolor, rotate, or add effects to the logo.
- Minimum size: ~120px wide for the horizontal lockup; ~24px for the mark.
- On busy photos, prefer the mark or the reverse lockup for legibility.
